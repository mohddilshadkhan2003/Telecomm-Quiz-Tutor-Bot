Evaluation

How it works

  1. Choose or type your answer to the question.
  2. The system retrieves relevant plan snippets and asks the LLM to evaluate your response.
  3. Receive a score, explanation, and evidence snippets for learning.
Run locally: python app.py

Open http://127.0.0.1:5000 in your browser.

Demo

Replace /static/demo.gif with a short GIF (3–8s) that shows the quiz flow. If no GIF is provided the static preview is used instead.

How to create a portfolio GIF (FFmpeg) 
# record a short mp4 (or screen capture) and convert to optimized gif
ffmpeg -i demo.mp4 -vf "fps=15,scale=800:-1:flags=lanczos" -y demo_temp.gif
# reduce colors and optimize
gifsicle --optimize=3 demo_temp.gif -o letstry/static/demo.gif
rm demo_temp.gif

Tip: Keep GIF under ~3MB for GitHub and portfolio pages.
